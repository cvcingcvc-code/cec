# HackerTrip 产品研究（HACKERTRIP_STUDY.md）

> 研究时间：2026-10-23。研究对象：hackertrip.space 公开页面（主站 / 白皮书 / explore / CLI 页 / 活动详情页）。
> 方法：WebFetch 只读观察公开网页 + 官方文档。**未**调用任何未授权内部接口，**未**提取微信小程序私有代码，**未**复制受保护素材。
> REA（github.com/morluto/rea）核实结论：该仓库是「逆向工程智能体工具集」（Hopper/Ghidra/Frida 桥接等），**与黑客松/活动发现无关**，不适用于本研究目标，故未使用——以浏览器观察与官方文档代替。

## 1. 产品定位

HackerTrip = 面向黑客松场景的一站式平台，覆盖**赛事发现 → 智能推荐 → 报名转化 → 主办方曝光 → 赛后沉淀**。五个入口：微信小程序（发现/订阅/AI 推荐/身份卡）、官网（赛事库/作品档案/SEO）、公众号（深度内容）、Haki 桌面版（参赛陪跑）、HackerTrip CLI + Skills（发作品/发赛事）。

## 2. 活动发现页（主页 + /explore）

**主页结构**（自上而下）：
1. Hero：一句话定位 + 三个入口 Tab（参加黑客松 / 举办黑客松 / AI 匹配）+ 小程序 + Event Radar
2. 「本周值得看的黑客松」编辑精选区：3 张卡（标题、日期、城市·副标题、X 天后截止）
3. 「主办方与社区 · 查看全部」
4. 「发现值得参加的黑客松」：即将开始(17) / 往届回顾(24) 双 Tab
5. 筛选条：**全部形式**（形式筛选）+ **截止优先**（排序）
6. 赛事卡片流：每卡含 标题、日期区间、城市+场地/形式徽标（混合/线下/线上）、状态徽标（进行中/报名已截止/X天后开始）、活动简介长文、奖金摘要、参与人数、倒计时
7. AI 匹配推广区：`curl -sfL hackertrip.space/install | bash` 三步安装 + /ht-scan-project 效果预览（项目画像→Top5 匹配分→报名路径）
8. FAQ + 主办方入驻

**/explore 列表页**：与主页卡流一致，更多赛事。卡片字段：标题、起止日期（Sep 11 – Nov 15, 2026 格式）、城市+形式徽标（混合/线下/线上）、状态徽标（进行中/报名已截止/9天后开始）、简介、奖金、参与数、倒计时。

**可验证证据**：主页真实展示了 17 场即将开始赛事（蚂蚁灵波具身大模型挑战赛、苏客松 2026、怀柔科学城 48h 黑客松、AI For Good 公益黑客松、PAYATHON 2026、AIY HACK LEAGUE、雾客松 2027、Delin Residency、天猫 AI 黑客松、TME 音乐 Hackathon、Caltech Mathathon、WTCC AI 硬件黑客松、Google Cloud AI Builder Cup、INTERCITY HACK 宁波站、枫客松等），全部带真实主办方与报名链接（飞书表单/天池/官网）。

## 3. 活动详情页（样本：/hackathon/ht-2026 苏客松 2026）

**结构（自上而下）**：
1. 海报区 + 标题 + 日期/城市 + Page 0 序章徽标 + **报名截止倒计时**（3天4时）
2. 常驻 CTA：**立即报名**（外链飞书表单，带 utm 追踪参数）
3. 结构化字段卡：报名截止（10月26日 23:59）、比赛时间、城市、场地与说明、参赛形式（线上+线下）、奖金池（总奖池超 50 万元：冠军 5 万现金+奖杯…）、赛题主题、团队规模
4. **主办方官网外链**（微信公众号文章，带 utm）
5. 正文四段：活动简介 / 挑战内容 / 活动日程 / 适合人群
6. 主办方信息（主办/指导/联合出品/特别支持 + 报名方式）
7. 赛道卡（赛道1 开放式命题…）+ 赛程卡（3 节点时间线：报名及初筛 → 线上路演初赛 → 线下决赛）

**关键交互**：地点一键唤起导航；底部常驻 订阅 / 转发 / 报名；订阅后截止前收提醒。

## 4. 活动搜索和筛选

- 三维浏览：**主题 × 城市 × 时间**（白皮书 §核心功能）
- 筛选控件：形式（全部形式/线上/线下/混合）、排序（截止优先）
- 状态区分：进行中 / 报名已截止 / X天后开始（未开始）/ X天后截止（倒计时）
- 无全文搜索框（以结构化筛选为主）；CLI 侧提供 `npx hackertrip match` 按技术栈匹配

## 5. AI 赛事推荐

**形态 A — 终端 Skill（/ht-scan-project）**：装到 Claude Code/Cursor/Windsurf。读 package.json、README、目录结构 → 输出 项目画像（名称/技术栈/领域）+ Top5 匹配（#1 AdventureX 92/100、推荐赛道、#2 87/100、#3 81/100）+ 报名路径。宣称 100% 本地运行，代码不上传。

**形态 B — Haki AI 助手（小程序/桌面）**：帮选手判断赛事适配度、拆解赛题、准备 Pitch；帮主办方答疑。

**诚实边界（值得学习）**：主办方提交时「奖金、日期不确定就留空，不要编造」；seo/GEO 声明「实际收录与排名由搜索引擎决定，不承诺具体位置」。

## 6. 收藏与订阅

- 订阅赛事 → 开赛、报名截止提醒（小程序内）
- 收藏后提供提醒能力；报名临近截止时继续触达
- 参赛身份卡：个人名片 + 工牌码，线下扫码交换/签到

## 7. 报名入口

- 三种方式：网页链接（飞书表单/天池/官网）、公众号文章、小程序直达
- 站内报名（白皮书标注「已上线」）：小程序内填表，主办方拿结构化名单
- 详情页 CTA 带 utm 参数（utm_source=hackertrip&utm_medium=referral&utm_campaign=hackathon_<id>_detail）——**外链报名+来源追踪**是主要模式
- 点击报名链接 ≠ 报名成功；站内报名需提交表单，站外报名由主办方系统确认

## 8. 参赛准备流程

- Haki 桌面版：倒计时与赛程节点提醒、**参赛材料清单自动推断**、赛事文档随时提问、45 分钟没 commit 防丢码提醒
- 赞助商 Token（GLM/Kimi/DeepSeek）一键写进 CLI 配置，原配置自动备份
- 过程留痕：token 用量、commit/push 节奏、活跃时长——本地计量，未绑定账号不同步；绑定后只同步统计特征与仓库名，**不同步源码、对话正文或本地路径**

## 9. 主办方活动提交

- CLI `npx hackertrip submit-event --organizer-no HT-XXXXXX --submit-key 密钥 --from event.json`
- 必填四件套：**名称 + 起止时间 + 城市 + 官网**；奖金/日期不确定留空
- 提交 → 草稿箱 → **平台人工审核** → 小程序+官网双端上架
- `event-status` 查询审核进度、待补充项、审核备注
- 宣称 48 小时内上线

## 10. 项目与赛事关联

- 作品详情页：获奖标记与奖项名由主办方评审后写入；作者个人主页看完整参赛履历；**关联赛事一栏直接指回赛事页**
- 数据闭环六层：曝光 → 报名 → 直播 → 作品 → 获奖 → 履历（反哺品牌曝光）

## 12. 对 Gorgon 的启示（详见 FEATURE_COMPARISON）

1. **结构化字段卡**（截止/时间/城市/形式/奖金/赛题/团队规模）是最有效的信息层级——Gorgon 已有同构字段，可对齐
2. **报名截止倒计时**是最强行动驱动——Gorgon 可在卡片与详情页加倒计时
3. **AI 匹配输出格式**：项目画像 + Top N 匹配分 + 推荐赛道 + 报名路径——Gorgon AI 匹配应对齐此输出，且必须诚实标注未知条件
4. **外链报名 ≠ 报名成功**：Gorgon opportunity-repository 已有正确的 6 态模型（opened_registration ≠ registered），比 HackerTrip 站外模式更严格，保持
5. **人工审核上架**：与 Gorgon review/queue 设计一致
