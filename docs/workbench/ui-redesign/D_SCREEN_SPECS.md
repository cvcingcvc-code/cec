## D4. 任务详情 — 已实现（结论前置）

**这是闭环的核心页面。** 目标顺序：**结论在前 → 下一步 → 记录 → 技术细节折叠**。

```
┌──────────────────────────────┐
│ ‹ 行动                        │
│ [已完成]  整理比赛资料         │  ← 状态徽章 + 标题 24
│ 目标：帮我整理一份比赛报名资料清单│  ← 目标（灰底卡）
│ 创建 10月12日 · 完成 10月13日   │
│                              │
│ ── 结论 ─────────────────     │  ← 结果摘要（ResultSummary）
│ 共找到 3 条相关结果            │
│ ▸ 大模型工作坊 9/20 杨浦 ¥免费  │
│   [查看来源 ↗]                │
│ ⓘ 技术详情（原始数据）         │  ← 折叠，默认收起
│                              │
│ ── 安排时间 ─────────────     │  ← 排期编辑（现已在顶部，位置合理）
│ 计划日期 [____]  截止 [____]   │
│ [保存排期]                    │
│                              │
│ ── 执行记录 ───────────       │
│ · 已电话确认，需带身份证  2h前  │  ← 笔记即记录
│ [记一笔________________]      │
│                              │
│ ── 执行详情（3 步）▸ ──────    │  ← 折叠：步骤/来源/处理方式/路由/时间线
└──────────────────────────────┘
│  [ 开始执行 ]                 │  ← PrimaryAction 底部固定 52dp
└──────────────────────────────┘
```

| 区块 | 状态 | 现状 → 目标 |
|---|---|---|
| 状态徽章 + 标题 + 目标 | 已实现 | 顺序保留 |
| 结论（结果摘要） | 已实现 | 从页面中部**上移到首屏**（`TaskDetailScreen.jsx:622` → 头部之后） |
| 排期 | 已实现 | 保留（`TaskDetailScreen.jsx:384-411`） |
| 执行记录（笔记） | 已实现 | 从底部上移（`:729`） |
| 步骤 / 来源 / 处理方式 / 路由 / 时间线 | 已实现 | **合并进「执行详情」折叠**（现状平铺 5 个区块，`:428,528,595,752,812`） |
