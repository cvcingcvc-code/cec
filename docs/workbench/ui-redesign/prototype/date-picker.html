规格要点

触控日期格 48×48dp，月份切换/关闭/底部按钮全部 ≥48dp
中文标题「2026年10月」，值「2026年10月14日 周三 14:00」，周一为每周首日
选中态实心 indigo 圆角 + 今日圆点，不靠颜色单一维度（含白色圆点/加粗）
禁用置灰 + disabled（不可点、不进焦点）
返回键Esc / 安卓返回键 = 取消并关闭，不写入任何值
无障碍格子 aria-label="2026年10月14日 周三"、aria-selected、月标题 aria-live

数据回填（格式不变）

单日 → 计划日期 写入本地 YYYY-MM-DD（scheduledDate）
日期+时间 → 截止时间 以本地时间转 toISOString()（dueAt），时区语义与现状一致
「清除」→ 写入 null，与现有 setTaskSchedule 的清空语义一致
