# B. 新信息架构

## B1. 设计原则（用于裁决所有层级争议）

1. **一个 tab 一件事**：底部导航每一项 = 用户的一个心智动作，不是系统的一个模块。
2. **行动优先**：任何页面首屏必须能回答"我现在该做什么"，而不是"系统里有什么"。
3. **闭环可见**：发现 → 行动 → 排期 → 执行 → 记录 → 复盘，六个步骤都能在 2 次点击内到达下一步。
4. **技术细节下潜**：引擎状态、原始 JSON、检索管线指标一律降级到"详情/设置"，不占主路径。
5. **单手可达**：主操作固定在屏幕下半区（底部操作条 / 右下浮动），列表项整行可点且高度 ≥ 56px。

## B2. 现状 vs 目标

| 维度 | 现状 | 目标 |
|---|---|---|
| 底部导航 | 工作台 / 搜索 / 任务 / 更多（9 项抽屉） | **今天 / 发现 / 行动 / 我的**（4 项，无抽屉） |
| 一级页面数 | 14 个（9 个藏在抽屉） | 4 个 tab + 5 个子页面 |
| 主入口 | 首页平铺 6 区块 | 首页 = 今日安排 + 一个输入框 |
| 日程 | 无独立页（散落在首页/任务筛选） | 「今天」内双视图（列表 / 周视图） |
| 笔记/记录 | 藏在项目详情与任务详情 | 「我的 → 记录」为一级子页面 + 任务详情内联 |
| 开发状态面板 | 首页底部主位 | 迁至「我的 → 关于与诊断」（折叠） |
| 引擎/路由细节 | 任务详情平铺 | 任务详情「执行详情」折叠区 |

## B3. 目标导航模型

```
底部导航（4 项，常驻，48dp 高 + 安全区）
├── 今天        TODAY     — 今天要做什么（默认首页）
├── 发现        DISCOVER  — 找活动 / 找机会（含检索与来源）
├── 行动        ACTIONS   — 我的任务与执行
└── 我的        MINE      — 项目 / 地点 / 记录 / 设置
```

## B4. 「我的」子页面结构（替代 9 项抽屉）

```
我的
├── 我的项目            （ProjectsScreen → ProjectDetailScreen）
├── 走访地点            （PlacesScreen）
├── 记录与笔记          （HistoryScreen + notes 合并视图）
├── 进度一览            （ProgressCenterScreen）
├── 待我确认            （ReviewCenterScreen）
└── 设置
    ├── 通用（语言/外观/地区默认）
    ├── 数据与存储       （本地数据量、清空演示数据）
    └── 关于与诊断       （版本、引擎状态面板 ← 从首页迁来）
```

抽屉被取消，全部入口以**列表行**（56dp，右 chevron）出现在「我的」，可滚动但一眼可数。

## B5. 闭环 → 页面映射（可点击路径）

| 闭环步骤 | 用户动作 | 落点 | 下一步引导 |
|---|---|---|---|
| ① 发现信息 | 在「发现」输入"周末的 AI 活动" | 发现 → 结果卡 | 卡上「加入行动」 |
| ② 创建行动 | 点「加入行动」/「以此创建项目」 | 行动（新建任务） | 跳任务详情，显示"尚未执行" |
| ③ 安排日程 | 任务详情「安排时间」→ 选日期/提醒 | 今天（列表/周视图出现） | Toast「已加入 10月14日」 |
| ④ 执行 | 任务详情底部主按钮「开始执行」 | 执行中（进度可见） | 完成后 → 结果区 |
| ⑤ 记录 | 结果区下方「记一笔」 | 任务详情记录区 + 我的→记录 | — |
| ⑥ 复盘 | 项目详情「本次复盘」 | 项目详情 | 进度一览汇总 |

**关键改动**：③ 与 ⑥ 现在没有独立入口，本设计给 ③ 新增「今天」双视图、给 ⑥ 保留项目复盘并汇总进「进度一览」。

## B6. 状态与权限层级（信息下潜规则）

| 信息 | 位置 | 理由 |
|---|---|---|
| 任务状态（7 态） | 列表徽章 + 详情头部 | 用户必须知道"现在到哪一步" |
| 排期（计划/截止） | 列表第二行 + 详情 | 决定"今天做什么" |
| 结果（中文摘要） | 详情首屏「结论」区 | 闭环产物，必须第一眼可见 |
| 原始 JSON | 详情「技术详情」折叠（已完成，保留） | 极少数人需要 |
| 引擎/路由/技能/处理方式 | 详情「执行详情」折叠（默认收起） | 开发者与演示需要 |
| 工作台状态面板 | 我的 → 关于与诊断 | 从首页迁出 |
| 检索管线指标 | 发现 → 结果数量旁的「ⓘ」 | 默认隐藏 |
