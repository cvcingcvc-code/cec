## 一句话定位

**Gorgon Workbench 是面向普通人的 Android 个人智能行动工作台**：把活动检索、生活日程、任务、地点、笔记、项目进度、人工确认和行动复盘放到一个地方。未来可由手机安全地将任务派发给用户本人常开电脑上的 AI 智能体，查看运行进度、审查高风险操作和取得结果。

不是单一“发现周末活动”的 App，不是只能聊天的 AI，也不是无审批的远程控制工具。

核心价值闭环：**发现信息 → 判断价值 → 创建任务 → 安排行程 → 现场/线上执行 → 记录结果 → 复盘和跟进**。

## 固定设计原则

1. **真实可用优先**：可安装、真实数据、完整操作、持久化是交付门槛；测试数量不能代替手机实际体验。
2. **统一数据与项目模型**：活动/求职/学习/地推/个人项目共享项目、任务、日程、地点、来源、笔记、复盘；不要做五套重复系统。
3. **本地优先，状态真实**：离线、超时、演示、缓存、真实数据有清晰提示；不得把打开报名链接记为报名成功。
4. **审计与用户控制**：任务有状态、执行者、来源、历史和产物；外部动作先展示提议，敏感/破坏性操作必须经用户明确批准。
5. **功能与体验分层推进**：每轮先修阻断，再做最小可用功能；同步处理可点击性和手机易用性；完整视觉美术与设计系统升级在核心闭环稳定后集中实施。
6. **禁止无限扩张**：每轮明确任务清单、完成条件、失败/阻断停止条件，产生可复核证据并更新 Issue/验收文件。

### V2.1 收尾：真实手机检查清单

1. 从 GitHub Release 下载最新 `app-release.apk`，核对 SHA256/版本，确保不是旧包。
2. 在物理 Android 手机上安装，冷启动不白屏。
3. 进入「更多 → 智能搜索」，输入“这个周末上海有什么 AI 活动？”，发起真实查询。
4. 确认 REAL SEARCH 标识、真实来源和非 DEMO/Mock 的结果；空结果/网络故障必须解释原因。
5. 打开结果详情及来源链接，核对网页实际可用。
6. 将结果保存到任务，设置日程和地点，再创建笔记。
7. 强制停止 App 并重启，检查任务、日程和笔记一致且无重复。
8. 分别测试 Wi-Fi/蜂窝或断网提示（条件不足就标 NOT_TESTED）。
9. 输出 PASS/FAIL/BLOCKED/NOT_TESTED 表，任何 P0 失败先修复；无真机不得宣称 V2.1 真机 PASS。

下一轮小修复候选（严格限量）：修复自动化探针截断解析 bug；在 CI 加入 APK 不带环境变量构建时的 URL 回归断言；修复真机找到的 P0 问题。不可因模拟器 qemu 进程不稳定无限重启。

## V2.2 最小可交付范围（V2.1 真机关键步骤通过后开始）

- **首页**：今天、待办、近期日程、重要提醒、项目进度入口，手机端一眼可懂。
- **统一对象**：`Project` 项目；`Task` 任务；`Opportunity` 信息机会/活动；`ScheduleItem` 日程；`PlaceVisit` 地点走访；`Note` 笔记；`Source` 可追溯来源；`Review` 复盘。先审计并复用现有结构，禁止无证据重写。
- **场景 A 活动**：真实查询 → 打开来源 → 保存 → 报名状态显式确认 → 排期/笔记/复盘。
- **场景 B 求职/学习**：记录岗位/课程线索 → 跟进任务 → 提醒 → 完成与复盘；不虚构岗位实时可用性。
- **场景 C 外勤**：走访地点 → 已去/未去/待回访 → 记录结果 → 下一次行动。位置和笔记默认本地保存，不默认公开分享。
- **质量保障**：移动端加载和错误反馈、日期/时区、去重、离线只读/待同步状态、重启持久化、来源诚实标注和真实端到端验收。

## V2.3 多项目进度模型（后续阶段）

每个项目至少可以看到：目标、阶段、任务、负责人（本人/Agent）、状态、优先级、开始与更新时间、阻断原因、可点击证据/产物、下一步、审计时间线。支持跨项目概览，**进度百分比只能根据已定义里程碑/任务计算，不得凭 AI 猜测**。

## V2.4 / V3.0 远程 Agent 安全预留（当前**仅设计**）

目标：用户在外，电脑常开，手机下达工作目标，电脑端有权限的 Agent（Codex/WorkBuddy/其他）执行并回传结果。

候选构件：
- `Device`：仅绑定用户许可的电脑与手机，安全身份与吊销机制。
- `AgentAdapter`：按工具能力适配；没有公开接口时不可宣称可自动控制。
- `TaskRun` / `RunEvent`：任务 ID、状态、时间线、日志摘要、产物、失败与重试，不凭猜测展示成功。
- `Approval`：读取/测试/写入/发布/删除等权限分级；敏感动作按规则审批，可取消、超时和撤销。
- 通信使用电脑端主动建立的加密认证连接，优先最小权限；不能通过公网暴露未验证的任意命令执行接口。
- 支持离线、恢复连接、重复消息幂等、设备丢失撤销、隐私与密钥保护。
