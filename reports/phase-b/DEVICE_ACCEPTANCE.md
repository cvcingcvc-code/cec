# DEVICE_ACCEPTANCE — Phase B 真机验收清单（用户回家后 10–20 分钟）

> 状态：**DEVICE_E2E = NOT_TESTED**（本轮无 ADB 设备；以下步骤需用户本人执行）
> APK：`Gorgon-Workbench-Android-v6.0.2-debug.apk`（versionCode 7，SHA256 `58ba0730…`）

## 快速验收（10–20 分钟）

### A. 安装（2 分钟）

1. 下载：https://github.com/cvcingcvc-code/cec/releases/tag/v0.3.1-alpha → `Gorgon-Workbench-Android-v6.0.2-debug.apk`
2. 传到手机（微信文件传输助手/USB/网盘均可），点击安装（允许未知来源）
3. 若已装 v6.0.0/v6.0.1（同为测试签名）可直接覆盖升级；若报 INSTALL_FAILED_UPDATE_INCOMPATIBLE，先卸载旧版

### B. 本地任务闭环（5 分钟）

4. 打开工作台 → 首页输入「准备明天的面试」→ 创建（自动跳转详情页）
5. 详情页：设置计划日期、关联地点（下拉）、记一条笔记、设置提醒（选 1 小时后）
6. **关闭应用**（从最近任务划掉）→ 重新打开 → 检查：任务/日期/地点/笔记/提醒是否全部保留
7. 手机通知栏：1 小时后是否收到提醒通知（首次设置时会请求通知授权，请允许）

### C. 电脑网关联动（5–10 分钟）

8. 电脑上启动网关（LAN 模式，需与手机同一 Wi-Fi）：
   ```
   node scripts/agent-gateway.mjs --port 8765 --lan
   ```
   记下控制台打印的 token（`scripts/.agent-gateway/token.json`）与局域网地址（如 `http://192.168.x.x:8765`）
9. **Windows 防火墙**：首次运行时若弹窗，允许 Node.js 的「专用网络」访问；或手动放行 8765 端口（专用网络入站规则）。不关闭整个防火墙
10. 手机 → 智能体页 → 输入电脑局域网地址 + token → 连接（应显示「已连接 · 3 个执行器」）
11. 提交任务：选 `repo.status` → 提交执行 → 等待 2 秒 → 查看结果（应显示真实 git 状态）
12. 在该执行记录点「关联到任务…」→ 选你创建的任务
13. 打开该任务详情页 → 应出现「电脑执行记录」卡片（状态 + 摘要 + 输出）
14. 把任务标记完成

### D. 回报

15. 报告真实结果：哪几步成功、哪几步失败（附截图/错误信息）

## 需要用户本人操作/授权的项

- 允许安装未知来源应用
- 允许通知权限（步骤 7）
- 允许 Windows 防火墙放行 8765（步骤 9）
- 手机与电脑同一局域网（步骤 8）

## 不在本轮范围

- 外网远程访问（手机不在家 Wi-Fi 时）——后续评估授权组网，禁止直接公网暴露网关
- Codex AI 远程执行——接口已验证，待用量恢复后建 Adapter（见 AGENT_ADAPTER_AUDIT.md）
