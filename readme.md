# Gorgon Lite — 个人 AI 行动助手

**把想法变成真实行动：创建任务 → AI/电脑端受控辅助执行 → 查看真实结果 → 保存记录与复盘。**

> 当前产品形态：**Gorgon Lite**（由原 Gorgon Workbench 精简演进）。本 README 严格对齐仓库真实代码能力，未实现或未真机验收的能力如实标注，绝不包装 Mock 或规划功能。

---

## 1. 核心闭环与主入口

Gorgon Lite 只围绕一个日常高频闭环设计移动端与桌面端体验，主导航精简为 **三个核心入口**：

1. **首页（Home）**：一句话输入目标并自动路由执行（幂等去重）、查看今日已排期任务、追踪最近执行结果与失败复盘。
2. **任务（Tasks）**：管理 7 态受控任务状态机、设置计划日期/截止时间/本地提醒、拆解子步骤、单独重试失败步骤、关联笔记与所属项目。
3. **智能体（Agent）**：配对连接局域网电脑端 Agent Gateway，仅暴露本机实测可用且获授权的只读执行器（仓库状态、文档阅读、主机概览、WorkBuddy 受限只读查询、Codex 只读诊断），如实展示未连接/超时/失败原因，集中处理需人工批准的事项，并将电脑执行记录关联回本地任务。

### 次级数据与历史归档（不丢任何历史数据）

- **次级入口**（右上角「工具」面板 / 任务页快捷栏 / 桌面侧栏次级分组）：**日程视图、笔记中心（含 TXT/MD 追加导入）、项目聚合、工作记录与 30 天回收站、人工确认中心、模型与设置**。
- **冻结与隐藏模块**：早期周末活动发现、关键词/自然语言找活动、活动地图、地点走访、自建活动、进度中心及 Python 采集管线默认从主导航隐藏并冻结扩展；原本地存档全部保留，可随时通过「模型与设置 → 已隐藏模块与历史数据入口」、`/?legacy=1` 或一键切换旧版导航（`/?nav=classic`）访问。

## 2. 当前真实能力状态（诚实分级）

### 已证实可用（代码 + 自动化测试通过）

| 能力模块 | 真实实现说明 |
|---|---|
| 任务引擎与持久化 | `gorgon_workbench_tasks_v2` 版本化存储、v1 自动无损迁移、损坏存档隔离备份（不清空）、30 天软删除回收站 |
| 一句话自动处理（One-Shot） | `one-shot.js` 归一化幂等去重、创建即运行确定性技能链（提取/规划/摘要/写作/搜索）、混合任务部分成功保留与失败步骤单独重试 |
| 排期、冲突提示与提醒 | `DatePickerSheet` 本地时区日期时间选择、截止冲突告警、Web 应用内轮询提醒 + Capacitor `LocalNotifications` 原生通知桥接 |
| 记录与复盘（笔记/项目） | 任务内直接记复盘笔记、四向关联（任务/项目/地点/活动）、TXT/Markdown 文件追加导入（2MB 上限） |
| 电脑端 Agent Gateway | `scripts/agent-gateway.mjs` 默认仅绑 `127.0.0.1`（显式 `--lan` 才开放局域网）、`X-Gorgon-Token` 鉴权、白名单执行器、60s 硬超时、协作取消、JSONL 审计日志 |
| WorkBuddy 受限只读适配 | 通过本机官方 `wbipc` 通道完成 HMAC 握手，仅开放 4 项只读查询（IPC 自检、登录账号、记忆档案摘要、云端智能体列表）；发消息与写操作明确拦截 |
| 安全与人工审批契约 | 敏感或带副作用的后续动作提案（`Proposal`）必须经用户人工点击「批准」才可执行；前端包内零密钥（`build-smoke` 强制扫描） |

### 受限 / 待真机验收 / 冻结项

| 项目 | 当前真实状态 |

## 3. 快速运行与验证命令

```bash
# 1. 安装前端依赖并运行单元测试、生产构建与安全扫描
cd app
npm ci
npm test            # Node 单元测试与网关安全/生命周期集成测试
npm run test:build  # Vite 生产构建 + 产物完整性与密钥泄露扫描（18 项检查）
npm run dev         # 启动本地开发预览

# 2. 按需启动电脑端受控 Agent Gateway（默认仅本机 127.0.0.1）
node scripts/agent-gateway.mjs --port 8765
# 若需同一局域网手机连接，必须显式传入 --lan：
node scripts/agent-gateway.mjs --port 8765 --lan
```
